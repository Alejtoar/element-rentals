# MVP Phase 1 — Frontend Scope
Elemnt Rentals

## Goal
Deliver a professional, mobile-first landing website that:
- Showcases properties
- Converts visitors into leads
- Attracts owner partners
- Sends all traffic into WhatsApp or backend leads

No customer portal yet.

---

## Pages Required

### 1. Home
Must include:
- Brand positioning
- Value proposition
- CTA for:
  - Guests
  - Property owners

---

### 2. Property Listing
Must show:
- Property cards
- Main photo
- Price per night
- Location
- "View property" button

---

### 3. Property Detail
Must show:
- Image gallery
- Description
- Amenities
- Price
- CTA buttons:
  - "Book via WhatsApp"
  - "Ask about this property"

These buttons must call backend-generated WhatsApp links.

---

### 4. Owner Partner Page
Must explain:
- How Elemnt Rentals works
- Commission model
- Benefits

Must include CTA:
- "List my property"
→ Opens WhatsApp or lead form

---

### 5. Admin (Basic)
Simple protected area for:
- Creating/editing properties
- Uploading images

---

## UX Rules
- WhatsApp CTA must be visible on every property
- Mobile-first
- No checkout or payments yet
- Simple and fast

---

## Integrations
- WhatsApp deep links from backend
- Property data from backend API

---

## Explicitly Excluded
Not in Phase 1:
- User accounts for guests
- Booking calendars
- Payments
- Owner dashboards
