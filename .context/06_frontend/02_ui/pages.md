# Pages — Elemnt Rentals (MVP Phase 1)

This document defines all public and admin-facing pages that must exist in the MVP.
Each page is mapped to a business goal.

---

## 1. Home

### Purpose
Introduce Elemnt Rentals and drive users to:
- Browse properties
- Contact via WhatsApp
- Attract owner partners

### Sections
- Hero section
  - Headline: "Premium Short-Term Rentals. Fully Managed."
  - Subheadline: Trust, convenience, returns
  - Primary CTA: "Explore properties"
  - Secondary CTA: "List your property"

- Value proposition
  - Full management
  - Transparent reports
  - No long-term contracts
  - 24/7 guest service

- Featured properties
  - Grid of 3–6 properties
  - Each links to property detail

- Owner partner section
  - Short explanation
  - CTA → Owner partner page

- Footer
  - WhatsApp contact
  - Company info
  - Social links

---

## 2. Property Listing

### Purpose
Allow guests to browse available properties.

### Content
- List of properties from backend
- Each card shows:
  - Image
  - Title
  - Location
  - Price per night
  - "View" button

Clicking a card opens Property Detail.

---

## 3. Property Detail

### Purpose
Convert interest into leads.

### Content
- Image gallery
- Property name
- Location
- Description
- Amenities
- Price per night

### CTA
Two primary buttons:
- "Book via WhatsApp"
- "Ask about this property"

These buttons must use WhatsApp deeplinks generated by backend.

---

## 4. Owner Partner Page

### Purpose
Convert property owners into leads.

### Content
- How Elemnt Rentals works
- Services offered
- Commission model
- Why partner with us

### CTA
Button:
- "List my property"

Opens WhatsApp or backend lead form.

---

## 5. Admin Login

### Purpose
Allow staff to manage properties.

### Content
- Email
- Password
- Login button

---

## 6. Admin Properties

### Purpose
Manage inventory.

### Features
- List properties
- Add property
- Edit property
- Upload images
- Publish/unpublish

---

## Page Flow Summary

Guest:
Home → Listing → Property Detail → WhatsApp

Owner:
Home → Owner Partner → WhatsApp

Admin:
Login → Admin Properties
