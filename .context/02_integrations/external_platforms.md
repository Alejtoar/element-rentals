# External Reservation Sources

Reservations may originate from the following sources:

## Platforms
- Airbnb
- Booking
- Vrbo
- Other future platforms

## Direct Channels
- Company website
- WhatsApp-assisted reservations
- Manual admin-created reservations
- Friends and family reservations

Each reservation must store:
- Source platform
- External reservation ID (if applicable)
- Synchronization status
