# Channel Manager Overview

The system supports reservations originating from multiple channels,
including external booking platforms and direct/manual sources.

A channel manager is responsible for:
- Synchronizing availability calendars
- Importing reservations
- Preventing double bookings
- Identifying the source of each reservation

The system may integrate with:
- Third-party channel managers (e.g. Lodgify)
- Direct platform APIs (Airbnb, Booking)
- Manual reservations created by administrators
